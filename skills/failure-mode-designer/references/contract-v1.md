# System Design Contract v1.0

Carry `contract_version: "1.0"`, `design_id: SD-*`, `mode`, `status`, and the standard state collections: functional requirements (`FR-*`), non-functional requirements (`NFR-*`), assumptions (`ASM-*`), estimates (`EST-*`), decisions (`DEC-*`), failure modes (`FM-*`), and validation findings (`SDV-*`). Each record includes status, source, confidence, and related IDs.
