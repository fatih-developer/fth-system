# System Design Contract v1.0

Carry `contract_version: "1.0"`, `design_id: SD-*`, `mode`, `status`, and state collections for `FR-*`, `NFR-*`, `ASM-*`, `EST-*`, `DEC-*`, `FM-*`, and `SDV-*` records alongside problem, architecture, interfaces, data topology, questions, and traceability. Every record has status, source, confidence, and related IDs. Data decisions must point to requirements, estimates, or assumptions.
