# System Design Contract v1.0

The orchestrator carries `contract_version: "1.0"`, `design_id: SD-*`, `mode`, `status`, and the state collections `problem`, `functional_requirements` (`FR-*`), `non_functional_requirements` (`NFR-*`), `constraints`, `out_of_scope`, `assumptions` (`ASM-*`), `estimates` (`EST-*`), `architecture`, `interfaces`, `data_topology`, `decisions` (`DEC-*`), `failure_modes` (`FM-*`), `validation_findings` (`SDV-*`), `open_questions`, and `traceability`. Stable IDs are never silently regenerated or deleted.
