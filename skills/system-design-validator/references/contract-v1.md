# System Design Contract v1.0

The validator consumes `contract_version: "1.0"`, `design_id: SD-*`, `mode`, `status`, problem, functional requirements (`FR-*`), non-functional requirements (`NFR-*`), constraints, out-of-scope, assumptions (`ASM-*`), estimates (`EST-*`), architecture, interfaces, data topology, decisions (`DEC-*`), failure modes (`FM-*`), validation findings (`SDV-*`), questions, and traceability. Findings use stable `SDV-*` IDs and include severity, rule, evidence, related IDs, remediation, owner, and status.
